  ↳ **Matt Murphy** · 2026-06-25

  > 💯💯💯Ali, great question and I think the line is pretty clean.
  > 
  > Using AI to help you understand, extend, test, document, or contribute to an open-source project is completely fair game, as long as you respect the project’s license, attribution, contribution rules, and maintainers.
  > 
  > That’s a win.
  > 
  > The ethical problem is not “AI helped me build it.”
  > 
  > The ethical problem is when someone takes an open-source project, strips attribution, ignores the license, ships unreviewed AI changes, or acts like they invented the whole thing.
  > 
  > Technically, I’d treat the AI agent like a junior developer with keyboard access: useful, fast, and absolutely not allowed to push unchecked code into anything important.
  > 
  > Fork it. Read the license. Understand the architecture. Make small changes. Run tests. Add tests. Review the diffs. Keep secrets out of the repo. Open PRs when appropriate.
  > 
  > That’s not cheating. That’s modern engineering with better leverage.👊😎
