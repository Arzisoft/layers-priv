# "I thought that was included."

"I thought that was included."

That sentence has ended more builder businesses than any bug, any outage, or any security breach.

Today I walk through three things you direct your AI to add to every proposal: an out-of-scope section, a change order process, and acceptance criteria for every deliverable. Protect yourself before the next client conversation.

-MM

**ORCHESTRATION PROMPT**

Direct your AI: "I am a software builder sending project proposals to clients. Create a proposal template with three protective sections: (1) An out-of-scope section template with 10 common exclusion categories for software projects (hosting management, third-party API costs, content creation, ongoing maintenance, training, data migration, etc.) with language I can customize per project. (2) A change order process document that defines how scope additions are requested, estimated, priced, and approved, including a change order form template. (3) An acceptance criteria framework with examples for common deliverables (dashboard, API, authentication system, reporting module) showing what 'done' looks like in measurable terms."

Scope creep is exactly where this all happens. So in step two, a change order process with a trigger and a price. Your AI can build a change order template that makes scope creep feel professional instead of confrontational. And step three, acceptance criteria for every deliverable. Not build me a dashboard.
