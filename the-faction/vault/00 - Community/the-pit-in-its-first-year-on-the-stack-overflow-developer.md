# In its first year on the Stack Overflow Developer Survey, Claude Code captured 1

In its first year on the Stack Overflow Developer Survey, Claude Code captured 10% market share. GitHub Copilot dropped from 67% to 51%.

That's not a shift. That's a landslide.

Among senior developers with 10+ years of experience, 46% now choose Claude Code versus 9% for Copilot. The people with the most context about what matters in production code are moving to agentic tooling at a rate that should make every developer org rethink their stack.

Here's what matters for operators watching from the outside: the shift from autocomplete to agentic coding isn't incremental. It's categorical.

Autocomplete tools work inside your editor and suggest the next line.

You're still driving.

Agentic tools work across your entire codebase, run terminal commands, manage files, and orchestrate multi-step workflows with genuine autonomy. The developer's role shifts from writing code to directing an engineering process.

I've watched this happen in real time across our builder community. The operators who adopted agentic workflows six months ago are shipping at 2-3x the velocity of those still using autocomplete-era tools.

Not because the tool is "better" in some abstract sense, but because the workflow is fundamentally different. You're no longer a typist with a suggestion engine. You're an engineering director with a staff that happens to be software.

The tools are consolidating fast. Windsurf rebranded to Devin Desktop after Cognition's acquisition. The stack that exists in January might look completely different by July.

This isn't about picking winners. It's about understanding that AI-directed engineering, where humans set direction and AI executes, is becoming the default mode, not the experimental one.

The question isn't which tool wins the market share war. It's whether your team is building the skills for a world where directing AI systems is the job, not a feature of the job.

The autocomplete era is over. The director's chair is open.
