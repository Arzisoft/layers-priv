# The activation gate is the first 48 hours. The habit gate is week three. Differe

*The activation gate is the first 48 hours. The habit gate is week three. Different problem, different solution. This is how to direct your AI to catch the churn signal before the cancellation email arrives.*

*—MM*

**ORCHESTRATION PROMPT: **

*Build a user activity monitoring system that tracks meaningful weekly actions per user. Establish a personal activity baseline for each user based on their first two weeks. Flag any user whose weekly activity drops below 50% of their baseline. Trigger automated re-engagement showing new features since their last session and progress from their user cohort. Do not use 'we miss you' language.*
