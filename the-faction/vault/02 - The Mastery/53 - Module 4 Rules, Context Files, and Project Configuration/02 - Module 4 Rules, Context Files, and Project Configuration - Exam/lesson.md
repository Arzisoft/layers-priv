# Module 4: Rules, Context Files, and Project Configuration — Exam

> Exam for **Module 4: Rules, Context Files, and Project Configuration** (The Mastery) — 25 questions, pass mark 80%. Correct answers are marked ✅ (read from each question's own post record; no quiz attempt was started to get them).

### Q1. A builder notices they have told the AI 'all dates in UTC' in six different sessions. Per this module, what does that repetition signal?

- **A.** The instruction belongs in a rules file, since anything you find yourself telling the AI twice should become a standing instruction  ✅
- **B.** The AI is defective, since a functioning model always retains instructions permanently across sessions without any configuration at all
- **C.** The instruction is unclear, since properly worded requests never require repeating and rewording is the fix for repetition
- **D.** The builder should switch models, since retention varies by provider and repetition means the current model forgets too fast

> **Answer:** A

### Q2. A builder asks what a .cursorrules file actually does. What does this module say?

- **A.** It encrypts the project, since the rules file is primarily a security boundary controlling which files the AI is permitted to read
- **B.** It stores conversation transcripts, since the rules file is the archive where past sessions persist for future model reference
- **C.** It contains instructions Cursor includes with your requests automatically, so standards written once get applied to every request  ✅
- **D.** It configures the editor theme and keybindings, since rules govern the interface while the AI is configured elsewhere entirely

> **Answer:** C

### Q3. A builder wants to know which instructions belong in rules versus a single request. This module gives a test. Which pair applies it correctly?

- **A.** 'Center that button' is a rule because it is specific; 'we use PostgreSQL' is a request because technology choices change over time
- **B.** 'We use PostgreSQL, all dates in UTC' is a rule because it is durable; 'center that button' is a request because it is momentary  ✅
- **C.** Both belong in rules, since any instruction of any kind is worth persisting and the rules file should capture everything you say
- **D.** Neither belongs in rules, since rules are reserved for legal boundaries and both technology and styling are session-level concerns

> **Answer:** B

### Q4. This module names four starting categories for a new rules file. Which set matches?

- **A.** The budget, the deadline, the client name, and the invoice terms, since project administration is what the AI most needs to know
- **B.** The stack, the conventions, the boundaries, and the style, written once so that the AI follows them on every request afterward  ✅
- **C.** The model, the temperature, the token limit, and the provider, since rules files are where generation settings get configured
- **D.** The theme, the font, the keybindings, and the extensions, since visual consistency is what rules files were designed to enforce

> **Answer:** B

### Q5. Two builders share a repo. One has a well-configured AI; the other's behaves completely differently on the same project. What does this module say went wrong?

- **A.** One builder's index is corrupted, since shared standards flow through the codebase index rather than through any rules file
- **B.** The second builder's account tier is lower, since rule enforcement is an account feature that varies by purchased plan level
- **C.** The builders are on different operating systems, since rules files are platform-specific and do not transfer across systems
- **D.** The rules were never committed to the repo, so one builder's AI is configured and the other's follows no shared standards at all  ✅

### Q6. A builder migrates their project off one database and onto another, but the AI keeps writing code for the old one. What does this module identify?

- **B.** A licensing conflict, since the old database's terms prevent the AI from generating code for its replacement in the same project
- **C.** Model memorization, since the AI trained heavily on the old database and no configuration can redirect it to the new one
- **D.** Index lag, since the codebase index refreshes monthly and the AI cannot see the new database until the next refresh cycle

> **Answer:** A

### Q7. A builder writes a rules file that runs eleven pages covering every preference they have ever had. What does this module predict?

- **A.** Perfect compliance, since more rules always produce more control and length is the single primary measure of a rules file's quality
- **B.** Faster responses, since a longer rules file gives the model more to work with and reduces the thinking each request requires
- **C.** The important instructions drown in noise, since a focused page outperforms a manifesto and every line should change behavior  ✅
- **D.** Automatic trimming, since Cursor enforces a rules length limit and silently deletes the excess beyond the first page anyway

> **Answer:** C

### Q8. A builder wants the AI to never touch the payments module unless explicitly asked. This module classifies this kind of rule and adds a step. Which?

- **D.** A style rule, verified by reading the payments code weekly to confirm the AI's formatting choices have not drifted over time
