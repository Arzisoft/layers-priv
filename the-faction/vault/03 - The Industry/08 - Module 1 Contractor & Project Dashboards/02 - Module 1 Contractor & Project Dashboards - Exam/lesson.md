# Module 1: Contractor & Project Dashboards — Exam

> Exam for **Module 1: Contractor & Project Dashboards** (The Industry) — 25 questions. Correct answers are marked ✅ (read from each question's own post record; no quiz attempt was started to get them).

### Q1. Your AI builds a construction dashboard that looks great on a laptop. The superintendent cannot read it on their phone at the job site. What went wrong?

- **A.** The dashboard uses a JavaScript framework that is incompatible with the mobile browser on typical field devices
- **B.** The hosting provider serves a lower-quality version of the site to mobile devices to reduce bandwidth usage
- **C.** The superintendent phone model is too old to render the modern dashboard components and needs an upgrade
- **D.** The interface was designed desktop-first with small text and tight layouts that fail in sunlight on a phone  ✅

> **Answer:** D

### Q2. A general contractor manages 15 subcontractors across 3 active sites. What should their dashboard prioritize?

- **A.** Portfolio-level visibility showing schedule status, budget health, and critical issues across all three projects  ✅
- **B.** Detailed daily reports from every crew member on every site so the GC can review individual work performance
- **C.** A single project view that defaults to the largest site since that project carries the most financial risk overall
- **D.** An equipment tracking page showing the location of every tool and vehicle across the three active job sites

> **Answer:** A

### Q3. Your AI generates a daily report form that requires a 500-word text description of work performed. Why is this a problem for field use?

- **A.** The form will exceed the mobile browser memory limit and crash when the superintendent tries to submit it
- **B.** Construction field workers are generally not trained to write detailed narratives and will submit inaccurate descriptions
- **C.** Field workers are standing on a job site holding a phone and typing 500 words is impractical in those conditions  ✅
- **D.** The text field will not save the entry if the cellular connection drops before the full description is submitted

> **Answer:** C

### Q4. A project manager views the schedule and sees that framing is delayed by one week. The timeline does not show what happens to downstream trades. What is missing?

- **A.** A notification system that sends automatic alerts to all downstream subcontractors when a predecessor is delayed
- **B.** Dependency tracking and critical path visualization that shows how the framing delay cascades to later tasks  ✅
- **C.** A manual override option that lets the project manager drag downstream tasks to new dates on the timeline
- **D.** A weather integration that explains the framing delay and predicts when outdoor work conditions will improve

> **Answer:** B

### Q5. A superintendent needs to submit a daily report from a job site with no cell signal. The platform shows a loading spinner. What is the failure?

- **A.** The loading spinner design is too small and the superintendent cannot determine whether the page is responding
- **B.** The hosting server is throttling requests from mobile devices causing longer load times at the network level
- **C.** The superintendent browser cache was cleared recently and the application has to reload all resources from scratch
- **D.** The platform lacks offline capability so core field functions cannot operate without an active data connection  ✅

> **Answer:** D

### Q6. Your construction platform shows a subcontractor the same dashboard view that the general contractor sees. What is the problem?

- **A.** The interface displays far too many simultaneous data points and the subcontractor phone experiences performance issues
- **B.** The general contractor dashboard uses terminology that subcontractors are not familiar with from their own trade
- **C.** Subcontractors should see only their own scope and payment status, not the full project financials and other trades  ✅
- **D.** The shared view creates a licensing issue because subcontractor accounts have fewer features than GC accounts

> **Answer:** C

### Q7. Your budget dashboard updates cost data on the first of each month. A change order is approved mid-month that increases costs by forty thousand dollars. When does the PM see it?

- **A.** Immediately, because change orders are separate from the budget cycle and always trigger a real-time notification
- **B.** Within twenty-four hours because the financial system processes change orders in a nightly reconciliation batch
- **C.** After the project accountant manually enters the change order into the budget system during the next review cycle
- **D.** Not until the next monthly update, meaning the project could be significantly over budget before anyone notices  ✅

> **Answer:** D

### Q8. Your construction platform captures field photos but does not store metadata. Why is this a problem for project documentation?

- **A.** Photos without metadata cannot be uploaded to the server because the storage system requires file metadata headers
- **B.** Without automatic timestamp, GPS location, and project association the photos lack the context needed for records  ✅
- **C.** The photo files will be too large without metadata compression and will consume excessive storage on the platform
- **D.** Project owners will not accept photo documentation unless each image includes a digital signature from the author

> **Answer:** B

### Q9. A superintendent needs to access the daily report, safety checklist, and timecard multiple times each day. The app buries these three levels deep in a menu. What is the issue?

- **A.** Core daily functions should be reachable within two taps from the home screen for field efficiency and adoption  ✅
- **B.** The menu structure should be reorganized alphabetically so all items are predictable regardless of nesting depth
- **C.** A search bar at the top of the app would solve the navigation problem without changing the existing menu design
- **D.** The superintendent can bookmark individual pages in the browser which eliminates the need for shortcut navigation

> **Answer:** A

### Q10. Your AI builds touch targets on the mobile interface at 24 pixels. A field worker wearing winter gloves cannot accurately tap buttons. What is the fix?

- **A.** Increase touch targets to at least 48 pixels ideally 60 or more with generous spacing between interactive areas  ✅
- **B.** Add a voice command layer so the field worker can navigate the interface without needing to touch the screen
- **C.** Require the field worker to remove their gloves when using the application since precise input needs bare fingers
- **D.** Replace all buttons with swipe gestures because swiping is easier than tapping when wearing protective gloves

> **Answer:** A

### Q11. Your platform syncs field data to the server when the device reconnects after being offline. How should it handle a conflict where the same record was edited on two devices?

- **A.** The platform should always keep the server version and discard the offline edits since server data is authoritative
- **B.** The platform should always keep the offline version and overwrite the server since the most recent edit wins
- **C.** The platform should flag the conflict, show both versions, and let the user choose which data to keep or merge  ✅
- **D.** The platform should prevent offline editing entirely so that no two devices can ever modify the same record at once

> **Answer:** C

### Q12. An owner wants to see project progress and budget on their dashboard. What level of detail is appropriate for this role?

- **A.** Full access to every financial line item including subcontractor pricing, labor rates, and material cost breakdowns
- **B.** High-level progress milestones and budget summary with percentage complete and variance from the original plan  ✅
- **C.** Access limited to only the final project completion date with no budget or schedule visibility during the build
- **D.** A duplicate of the project manager view since the owner is funding the project and deserves complete visibility

> **Answer:** B

### Q13. Your construction app uses light gray text on a white background for field data labels. Field workers complain they cannot read the screen outside. What is the fix?

- **A.** Switch to high-contrast colors with dark text on light backgrounds and ensure a minimum contrast ratio for sunlight  ✅
- **B.** Add a brightness boost button that increases the phone screen brightness to maximum when the user taps it
- **C.** Instruct field workers to cup their hand around the phone screen to create shade when reading outdoors on site
- **D.** Reduce the amount of text displayed and replace all labels with icons that are easier to identify in bright light

> **Answer:** A

### Q14. Your AI builds a project timeline as a simple list of tasks with start and end dates. The PM cannot see which tasks drive the completion date. What should you add?

- **A.** Color coding that assigns a different color to each trade so the PM can visually group tasks by subcontractor
- **B.** A percentage complete column next to each task so the PM can track progress on individual activities daily
- **C.** A filter that lets the PM sort tasks by deadline so the most urgent items always appear at the top of the list
- **D.** A Gantt chart view with dependency lines and critical path highlighting that shows which sequence drives the date  ✅

> **Answer:** D

### Q15. A field worker captures 20 photos of rebar installation for project records. The photos save with generic filenames and no context. What metadata is missing?

- **A.** The name of the photographer and their employee ID number so each photo can be attributed to its source
- **B.** A written description of the image content that the field worker must type before the photo can be saved
- **C.** Automatic timestamp, GPS coordinates, and project association so each photo has context without manual entry  ✅
- **D.** A quality rating score assigned by AI image analysis that determines whether the photo meets documentation standards

> **Answer:** C

### Q16. Your platform stores all data on the server with no local caching. A foreman at a remote site cannot load the safety checklist. What architecture change is needed?

- **A.** Move the entire application to a CDN closer to the job site region so the data loads faster over weak connections
- **B.** Implement service workers and local storage to cache critical data on the device for offline-first field access  ✅
- **C.** Add a download button that lets the foreman manually save the safety checklist as a PDF before going to the site
- **D.** Require the job site to install a dedicated WiFi router so all field devices have a reliable persistent connection

> **Answer:** B

### Q17. Your daily report interface uses free-text fields for weather, crew count, and work performed. How should you redesign it for field speed?

- **A.** Replace text fields with dropdowns, number pickers, and pre-populated templates to minimize typing on site  ✅
- **B.** Add auto-correct and predictive text support so the free-text fields are faster to fill out on a mobile keyboard
- **C.** Reduce the number of required fields to just the work performed description and make everything else optional
- **D.** Add a dictation feature that converts speech to text so the superintendent can describe work without any typing

> **Answer:** A

### Q18. A GC uses your platform on their laptop in the office and on their phone between site visits. The two interfaces show different navigation patterns. What is the problem?

- **A.** The laptop version runs a different codebase than the mobile version and the two are out of sync on features
- **B.** The hosting platform serves different interface bundles based on device type which introduces layout variance
- **C.** The GC browser is caching an older version of the desktop layout while the phone always loads the latest build
- **D.** The responsive design should maintain consistent navigation patterns across devices so users do not have to relearn  ✅

> **Answer:** D

### Q19. Your cost tracking dashboard shows budget and actual costs but does not show committed costs from approved purchase orders. What is the gap?

- **A.** A forecast column projecting the final cost based on the current spending trajectory and remaining work
- **B.** A historical comparison view showing how current costs compare to similar projects the contractor completed before
- **C.** Committed costs from approved orders that are not yet invoiced so the PM sees the full financial picture early  ✅
- **D.** A contingency reserve line that tracks the remaining buffer available for unforeseen cost increases on the project

> **Answer:** C

### Q20. Your AI builds a construction platform with a single user role. Every user sees the same interface. What problem does this create?

- **A.** The platform will run slower because every user loads the full dataset even if they only need a small portion
- **B.** Subcontractors see GC pricing and project financials, and owners see trade-level detail they do not need or want  ✅
- **C.** The interface becomes too cluttered for mobile screens because all roles have their controls visible at once
- **D.** Regulatory compliance requires separate user roles in construction software and a single role violates building codes

> **Answer:** B

### Q21. Your platform shows a project is on schedule, but the electrical subcontractor just told the PM they are two weeks behind. Where is the disconnect?

- **A.** The PM entered the original schedule correctly but forgot to mark the electrical trade as a critical path activity
- **B.** The platform calendar is set to a different timezone than the job site causing date calculations to display incorrectly
- **C.** The electrical subcontractor is using a different project management tool and the data is not integrated properly
- **D.** The schedule was not updated with actual progress from the field so the dashboard still reflects the original plan  ✅

### Q22. Your construction app requires the user to create an account with email verification before they can access any features. Why is this a barrier for field adoption?

- **B.** Account creation adds recurring monthly costs that subcontractor companies are unwilling to pay for their crews
- **C.** Email verification requires a strong internet connection that most job sites cannot provide for new user signups

- **B.** Hide the data table entirely on mobile devices and only show it when the user switches to a desktop browser

- **D.** Paginate the table into pages of ten rows each so the superintendent steps through smaller batches of data

### Q24. Your platform sends a push notification to the superintendent every time any project record changes. They receive 90 notifications per day. What is wrong?

- **A.** Push notifications should be disabled entirely on construction platforms since they interrupt active job site work
- **B.** Notifications should be filtered by role and urgency so superintendents only receive alerts relevant to their scope  ✅
- **C.** The platform should batch all notifications into a single daily summary email sent at the end of the work shift
