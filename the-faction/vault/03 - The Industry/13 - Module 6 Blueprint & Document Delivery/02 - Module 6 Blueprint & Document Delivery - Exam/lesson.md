# Module 6: Blueprint & Document Delivery — Exam

> Exam for **Module 6: Blueprint & Document Delivery** (The Industry) — 25 questions, pass mark 80%. Correct answers are marked ✅ (read from each question's own post record; no quiz attempt was started to get them).

### Q1. Three subcontractors build from Revision 2 of the structural drawings while the current version is Revision 3. Rework costs are $50,000. What system failed?

- **A.** The architect did not distribute the revision through the proper channels and relied on email without confirmation
- **B.** The subcontractors should have checked the plan room themselves because revision tracking is not the platform job
- **C.** The project manager should have held a meeting to verbally confirm that every trade received the latest drawings
- **D.** The platform should track revision distribution with receipt confirmation so outdated documents are flagged automatically  ✅

> **Answer:** D

### Q2. A superintendent needs to check a structural detail on a 150MB blueprint PDF. Their phone has weak cellular signal on the job site. The download stalls. What should the platform provide?

- **A.** A text-only version of the blueprint that transmits the dimensional information without any of the graphical plan drawings
- **B.** Tiled rendering that loads only the visible portion at full resolution instead of requiring the entire file download  ✅
- **C.** An automatic compression setting that reduces the file to under 5MB by lowering the resolution to a preview quality
- **D.** A request system where the superintendent texts the detail location and the office replies with a cropped screenshot

> **Answer:** B

### Q3. Your platform stores all project documents in a single folder with no organization by project, type, or revision. A PM searches for a specific submittal. What happens?

- **A.** The search requires scanning every file in storage because there is no structured path or metadata to narrow results  ✅
- **B.** The platform automatically categorizes documents by analyzing their content using AI during the search operation
- **C.** The PM can find the document by sorting the folder alphabetically since all construction documents follow naming rules
- **D.** The document cannot be found at all because the platform search function only works on structured folder hierarchies

> **Answer:** A

### Q4. Your platform issues a new plan revision but has no way to confirm that recipients viewed it. Two trades miss the update. What tracking feature is missing?

- **A.** A mandatory reply email that each recipient must send back confirming they downloaded and printed the new revision
- **B.** A physical sign-off sheet at the job site trailer where every subcontractor must initial next to the revision number
- **C.** Distribution tracking that records who received, opened, and acknowledged each revision with timestamps per recipient  ✅
- **D.** An automatic read receipt on the notification email that the platform sends whenever a new revision is made available

> **Answer:** C

### Q5. Field workers need access to the current plan set while working in a basement with no cellular signal. The platform requires internet for all document access. What is the fix?

- **A.** Install a cellular signal booster in the basement to ensure field workers always have connectivity underground
- **B.** Print the current plan set and distribute hard copies to every floor including below-grade work areas on the project
- **C.** Require field workers to review all needed documents before going underground and work from memory while below
- **D.** Enable offline pre-download of critical documents so the current plan set is cached locally on the field device  ✅

> **Answer:** D

### Q6. Your document server is in Virginia. A job site in Montana experiences 8-second load times for every blueprint. What infrastructure improvement helps?

- **A.** Upgrade the Virginia server to a faster processor so it can serve blueprint files more quickly to all remote locations
- **B.** Deploy a CDN that caches documents at edge locations closer to the job site to reduce the geographic network latency  ✅
- **C.** Compress all blueprint files to under 10MB so the smaller file size compensates for the distance to the server
- **D.** Schedule document downloads for overnight hours when network traffic is lower and bandwidth is more available

> **Answer:** B

### Q7. Construction photos are stored with no metadata. The PM needs all rebar inspection photos from March. They have to scroll through 5,000 images. What should the platform require?

- **A.** Structured metadata at capture time including project, date, GPS location, trade, and phase so photos are searchable  ✅
- **B.** A manual tagging workflow where the PM reviews and categorizes each photo after it has been uploaded to the system
- **C.** AI image recognition that automatically identifies the content of each photo and assigns categories without metadata
- **D.** A limit of 500 photos per project to keep the library manageable since most photos are redundant documentation

> **Answer:** A

### Q8. An RFI references Drawing S-201 Revision 2. The platform updates the reference link when Revision 3 is issued. Why is this wrong?

- **A.** The RFI should not reference specific drawings at all because the question may apply to multiple revisions over time
- **B.** Revision 3 contains the answer to the RFI so the updated link is correct and helps the reader find the resolution
- **C.** Document references in RFIs must be version-locked to the revision current when the reference was made for accuracy  ✅
- **D.** The platform should delete the RFI entirely when the referenced drawing is superseded by a newer revision number

> **Answer:** C

### Q9. Your platform delivers full-resolution 200MB PDFs to every field worker phone by default. Most workers only need to view a small section. What optimization should you implement?

- **A.** Limit blueprint access to supervisors only since field workers can ask their foreman to look up specific details
- **B.** Convert all blueprints to low-resolution JPEG images so they load quickly on any device regardless of connection
- **C.** Require workers to request specific pages from the office and receive them as individual email attachments per page
- **D.** Progressive download with resolution-appropriate delivery so workers see the section they need without loading everything  ✅

> **Answer:** D

### Q10. Your plan set tracking shows Revision 3 is current but the superintendent on site has only viewed Revision 1. What should the platform alert?

- **A.** The architect should be notified that their revisions are not being reviewed and asked to resend the distribution
- **B.** The superintendent and their PM should receive an alert that the super has not viewed the two most recent revisions  ✅
- **C.** The project should be paused until all team members confirm they have viewed and printed the current plan revision
- **D.** The platform should automatically revert the superintendent view to Revision 1 since that is what they last reviewed

> **Answer:** B

### Q11. Your photo storage stores images as flat files with auto-generated names like IMG_4521.jpg. A lawyer requests all foundation photos from October 2024. How do you find them?

- **A.** You cannot efficiently because without structured metadata there is no way to filter by project phase date or trade  ✅
- **B.** Search the file modification dates on the storage server because those dates correspond to the date each photo was taken
- **C.** Use AI image analysis to identify which photos contain foundation work and filter by the detected content type
- **D.** Ask the superintendent to identify the photos from memory since they were present when the foundation was poured

> **Answer:** A

### Q12. Your platform allows anyone on the project to upload documents without requiring any metadata fields. Why does this create problems at scale?

- **A.** The upload queue slows down because the server must process each document without metadata to determine its type
- **B.** Documents without metadata are stored in a temporary folder that the platform purges after a thirty-day retention
- **C.** Untagged documents become unsearchable and unretrievable once the project has thousands of files in the system  ✅
- **D.** The platform cannot generate a table of contents for the project document library if metadata fields are missing

> **Answer:** C

### Q13. Your platform serves documents from a single region. The company has job sites across six states. What performance pattern will remote sites experience?

- **A.** Higher latency and slower document load times that increase with geographic distance from the server location  ✅
- **B.** Identical performance to local sites because modern internet infrastructure eliminates geographic latency entirely
- **C.** Faster performance for remote sites because the server prioritizes long-distance requests over local traffic load
- **D.** Intermittent connection failures because single-region hosting cannot maintain stable links across state lines

### Q14. Your version control labels revisions as Rev 1, Rev 2, Rev 3 but does not show what changed between versions. The PM cannot tell what is different in Rev 3. What is missing?

- **A.** An automatic visual diff tool that overlays the two revisions and highlights every pixel that changed between them
- **B.** A requirement that the architect submit a complete new drawing set with no reference to the previous revision content
- **C.** A side-by-side comparison view that displays both revisions full size so the PM can visually scan for differences
- **D.** A revision description or change summary field that documents what was modified between the current and prior version  ✅

> **Answer:** D

### Q15. Your platform supports document upload but not search by document type. The PM needs all shop drawings for the mechanical trade. How do they find them?

- **A.** Browse through the full project document list manually and identify shop drawings by reading each file name individually
- **B.** A search and filter system that lets users query by document type, trade, revision status, and date range in seconds  ✅
- **C.** Export the entire document library to a spreadsheet and use spreadsheet filters to isolate the mechanical shop drawings
- **D.** Ask the mechanical subcontractor to resend all their shop drawings via email since the platform cannot filter them

### Q16. Your platform allows plan revisions to be uploaded without marking the previous version as superseded. Both appear as current. What risk does this create?

- **A.** The storage system charges double because two current versions of the same document consume premium storage space
- **B.** The platform search returns both versions every time which slows down the query performance significantly for users
